# Live Demo

Below is a live, interactive demo of vue-stack-tabs showcasing all features. The demo is embedded directly into the documentation—no separate server needed!

<FullDemo />

## Demo Features

Use the buttons above the demo to explore:

### Basic Usage

- 🏠 **Home**: Non-closable default tab
- 📄 **About/Contact**: Closable tabs
- 📑 **Multiple Tabs**: Open several tabs at once

### Advanced Features

- 📜 **Scroll Position**: Automatically saved and restored
- 📝 **Form State**: Input values preserved when switching tabs
- 🔗 **Nested Routes**: Navigate within a tab (forward/backward)
- 🎲 **Dynamic Tabs**: Create tabs on-the-fly with unique IDs

### Tab Operations

- Right-click tabs for context menu
- Close left/right/others/all
- Refresh current or all tabs

## Try It Out

1. Click any button to open a tab
2. Fill in the form on the "Form Demo" tab
3. Switch to another tab and come back—your input is preserved!
4. Scroll down on the "Scroll Demo" tab, switch tabs, then return—your position is remembered!
5. Right-click any tab to see the context menu options
